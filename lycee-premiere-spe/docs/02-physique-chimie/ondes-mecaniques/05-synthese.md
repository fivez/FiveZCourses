# 5. Synthèse et fiche de révision — Ondes mécaniques

## Définitions à connaître

- **Onde mécanique** : propagation d'une perturbation dans un milieu matériel, avec transport d'énergie et sans transport global de matière.
- **Période $T$** : durée d'un motif temporel complet.
- **Fréquence $f$** : nombre de périodes par seconde.
- **Longueur d'onde $\lambda$** : distance de répétition spatiale, entre deux points consécutifs en phase.
- **Célérité $v$** : vitesse de propagation de l'onde.
- **Foyer** : point de rupture en profondeur.
- **Épicentre** : projection du foyer à la surface.
- **Triangulation** : localisation par intersection de cercles de distances connues.

## Formules indispensables

| Situation | Formule |
|---|---|
| Télémètre ultrasonore | $d=v\Delta t/2$ |
| Portée théorique | $d_{\max}=v\Delta t_{\max}/2$ |
| Fréquence | $f=1/T$ |
| Période | $T=1/f$ |
| Célérité d'une onde périodique | $v=\lambda/T=\lambda f$ |
| Longueur d'onde | $\lambda=v/f$ |
| Décalage P-S | $\Delta t=t_S-t_P$ |
| Distance sismique simplifiée | $d=\Delta t/(1/v_S-1/v_P)$ |

## Points de vigilance

!!! attention "Erreurs fréquentes"
    - oublier le trajet aller-retour du télémètre ;
    - oublier de convertir les ms en s ;
    - confondre période temporelle et longueur d'onde ;
    - utiliser $v=\lambda f$ avec des unités non cohérentes ;
    - croire que tout signal périodique est sinusoïdal ;
    - confondre foyer et épicentre ;
    - croire qu'une seule station suffit à localiser un épicentre.

## Méthode universelle de résolution

1. Faire un schéma et nommer les grandeurs.
2. Identifier la grandeur recherchée.
3. Écrire la relation littérale avant le calcul.
4. Convertir toutes les données en unités SI.
5. Isoler l'inconnue.
6. Effectuer le calcul et vérifier l'ordre de grandeur.
7. Conclure par une phrase avec unité.
